# 📊 Retailers Data Dashboard – Excel

## 📌 Project Overview

This project is an interactive Retailers Data Dashboard created using Microsoft Excel.

The dashboard provides an overview of retailer sales performance, operating profit, units sold and pricing information through interactive filters, KPI cards, tables and charts.

## 🎯 Key KPIs

- 💰 Total Sales
- 📈 Average Operating Profit
- 📦 Units Sold
- 💵 Price per Unit

## 📊 Dashboard Features

- Sales by Retailer
- Sales by Beverage Brand
- Retailer Profit Margin
- Year-wise Sales Comparison
- Variance Analysis
- State-wise Filtering
- Region-wise Filtering
- Interactive Excel Slicers

## 🗂️ Dataset

The dataset contains information related to:

- Retailer
- Retailer ID
- Invoice Date
- Region
- State
- City
- Beverage Brand
- Price per Unit
- Units Sold
- Total Sales
- Operating Profit
- Operating Margin

## 🛠️ Tools & Skills

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Slicers
- Data Analysis
- Data Visualization

## 🎯 Project Objective

The objective of this project is to transform retailer sales data into an interactive Excel dashboard that helps analyze sales performance, operating profit, units sold, pricing and retailer-level performance.
